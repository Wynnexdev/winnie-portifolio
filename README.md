# Winnie Nyambura - Portfolio

A modern, responsive, and performance-conscious portfolio website for Winnie Nyambura, a Full-Stack JavaScript Developer based in Nairobi, Kenya.

## 🚀 Features

- **Responsive Design**: Mobile-first architecture that looks great on all devices.
- **Modern UI**: Dark mode with vibrant gradients, glassmorphism UI components, and fluid layout.
- **Interactive Elements**: Custom typing effects, smooth scrolling, and scroll-triggered animations.
- **Zero Frameworks**: Built entirely using HTML5, CSS3, and vanilla JavaScript (ES6+).

## 🛠️ Technologies Used

- **HTML5**: Semantic markup for accessibility and SEO.
- **CSS3**: CSS Variables for theming, CSS Grid & Flexbox for layout, custom animations.
- **JavaScript (Vanilla)**: DOM manipulation, Intersection Observers for scroll animations.
- **Fonts & Icons**: Google Fonts (Outfit, Inter, Fira Code) and FontAwesome.

## 📂 Project Structure

```
.
├── index.html   # Main portfolio layout and content
├── style.css    # Custom styles, variables, and animations
├── script.js    # Interactivity and scroll logic
└── README.md    # Documentation
```

## 💻 Getting Started

To view the project locally:

1. Clone or download this repository.
2. Open `index.html` in your web browser, or use a tool like Live Server in VS Code to run it locally.

No build tools or package managers are required!
